1. git init -b main
Initializes a new local Git repository in the project folder and sets the default branch name to 'main'.

2. git add <file> / git add .
Stages new or modified files in the working directory so they are ready to be recorded in the next commit.

3. git commit -m "message"
Saves a permanent snapshot of the staged changes into the local repository history with a descriptive message.

4. git branch feature
Creates a new branch named 'feature' to isolate new development work from the 'main' branch.

5. git checkout <branch-name>
Switches the active working directory to the specified branch ('feature' or 'main').

6. git merge --no-ff feature -m "message"
Integrates changes from the 'feature' branch into 'main' and creates a merge commit to preserve branch history.

7. git log --oneline --graph --all
Displays the complete commit history in a compact visual graph showing all commits, branches, and merges.

8. git status
Displays the current state of the working directory and staging area, verifying which files are tracked, untracked, or ignored by .gitignore.

9. git revert HEAD --no-edit
Safely undoes the changes from the most recent commit by creating a new inverse commit while preserving repository history.

10. git remote add origin https://github.com/achal22-coder/git-workflow-assignment.git
Links the local Git repository to the remote public repository on GitHub under the alias 'origin'.

11. git push -u origin main
Uploads all local commits and branch history from 'main' to the remote GitHub repository and sets upstream tracking.
